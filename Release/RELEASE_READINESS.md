# Hushto 배포 준비 및 검증 결과

2026-10-09 · Xcode 27 · iOS 17 이상 · 1.0.0 (2)

## 이번 수정

- 무음 요청은 공식 셔터음 억제 지원 시 무음 사진, 미지원 시 최대 네이티브 영상 프레임으로 처리. 타임아웃·중단 시 유음 일반 촬영으로 전환하지 않음.
- 연속 요청 차단, 촬영 상태 표시, 이전 타임아웃의 새 요청 취소 방지.
- 설정 → 촬영 방식 확인: 영상 프레임 횟수, 시스템 사진 요청 횟수, 해상도 및 사용자 선택 진단 공유.
- 개인정보처리방침, 도움말, 저장 PDF·동영상 삭제 확인 추가.
- PrivacyInfo.xcprivacy: 수집·추적 없음, UserDefaults CA92.1 및 부팅 이후 경과 시간 35F9.1 선언.
- 자체 제작 앱 아이콘, 시뮬레이터 학습 노트 샘플. 실제 iPhone 빌드에서 데모 에셋 제외.
- 세션·이미지 파일 보호, 이미지 비교 버퍼의 메모리 수명 보장.
- 손상된 한 장의 이미지가 빈 PDF로 발행될 수 있던 문제 수정. 누락 페이지는 저장 실패로 안내.
- 스토어 설명·심사 메모 및 공개 정책·지원 HTML 초안 준비.

## 무음 구현의 의미

iOS 18 이상에서 AVCapturePhotoOutput.isShutterSoundSuppressionSupported가 참인 경우에만 AVCapturePhotoSettings.isShutterSoundSuppressionEnabled를 켜고 최대 사진 크기로 촬영합니다. 지원하지 않으면 AVCaptureVideoDataOutput의 최대 네이티브 프레임을 저장합니다. 공개 API만 사용하며 타임아웃 때 유음 일반 촬영으로 전환하지 않습니다. 자동 스캔도 같은 무음 경로 선택을 따릅니다.

테스트는 코드 경로와 합성 프레임 처리의 확인입니다. 실제 센서 동작·촬영음·기기별 정책은 확인하지 못했습니다. 모든 기기·지역의 무음을 보장하거나 심사 통과를 보장하지 않습니다.

## 실제 iPhone에서 확인할 순서

1. 무음 켜기 → 10회 촬영 → 설정의 촬영 방식 확인에서 영상 프레임 또는 공식 무음 사진 합계 10회 증가, 유음 시스템 사진 요청 증가 없음 확인.
2. 외부 기기로 촬영 순간의 소리를 듣거나 녹음. 미디어 볼륨, 벨소리/무음 상태 각각 확인. 기기 모델·판매 지역·iOS 버전을 기록.
3. 무음 끄기 → 일반 사진 요청 증가 확인. 무음 검증과 구분하여 기록.
4. 전후면 전환, 백그라운드 복귀, 권한 거절 후 허용, 빠른 연속 터치, 자동 촬영, 동영상 중단·재생 확인.
5. 작은 글씨, 어두운 환경에서 고해상도 문서 가독성과 장시간 발열·메모리 확인.
6. PDF 공유·사진 저장 및 저장 공간 부족 오류를 실제 환경에서 확인.

## 제출 전 남은 항목

- 개발자명·문의 이메일 확정. 앱 Info.plist의 HushtoSupportEmail에 실제 이메일을 넣으면 문의 링크가 표시됨.
- Web/privacy.html과 support.html은 게시 전 초안. 운영자·연락처 추가, 초안 안내 제거, 공개 HTTPS URL 게시 후 App Store Connect 등록.
- 실기기 테스트 및 실제 앱 흐름의 최종 스크린샷 준비. 샘플 카메라 캡처만으로 완성된 스토어 스크린샷 세트라고 주장하지 않음.
- Apple Developer 배포 프로비저닝과 배포 서명, Archive 업로드, 개인정보 응답·연령 등급·판매 지역·심사 연락처 확정.
- 현재 로컬 Apple Development 인증서는 확인됨. 이번 Release 확인은 CODE_SIGNING_ALLOWED=NO 빌드이며 제출 가능한 IPA 검증은 아님.

앱 안 방침과 App Store Connect의 공개 방침 URL, 정확한 메타데이터, 촬영·녹화 시 명확한 표시가 필요합니다. [Apple 심사 지침](https://developer.apple.com/app-store/review/guidelines/) 및 [앱 개인정보 관리](https://developer.apple.com/help/app-store-connect/manage-app-information/manage-app-privacy/) 기준을 확인했습니다. 실제 승인 여부는 Apple 심사에서 결정됩니다.
