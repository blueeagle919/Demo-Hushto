Hushto 개인정보처리방침

게시 전 초안: 개발자명과 문의 연락처 확정 후 공개 서버에 게시해야 합니다.

Hushto는 계정, 광고, 분석 SDK 없이 동작하는 오프라인 문서 스캔 앱입니다. 앱이 운영하는 서버로 사진, 문서, 설정 또는 기기 정보를 전송하지 않습니다.

카메라는 사용자가 요청한 사진·문서 촬영 및 오디오 없는 영상 녹화에 사용합니다. 촬영 화면과 완료 표시를 제공합니다. 카메라 권한은 iOS 설정에서 변경할 수 있습니다.

사진 가져오기는 iOS 사진 선택기를 사용하여 사용자가 선택한 항목만 읽습니다. 사진·동영상 촬영 후 자동 저장하거나 스캔 페이지의 ‘사진 앱에 저장’을 누를 때 사진 추가 권한을 요청합니다. 마이크, 위치, 연락처 권한은 요청하지 않습니다.

문서·칠판·스크린 스캔의 원본, 보정 이미지, 페이지 순서와 PDF는 앱의 문서 폴더에 저장합니다. 사진·동영상 모드의 촬영본은 사진 앱에 바로 저장하며 PDF 스캔 세션에 넣지 않습니다. 동영상은 사진 앱으로 저장하는 동안 임시 파일을 사용하고 사진 앱 저장에 성공하면 임시 파일을 삭제합니다. 기본 모드 등의 설정은 앱의 UserDefaults에 저장합니다.

촬영 페이지는 페이지 관리에서 삭제할 수 있습니다. 저장 파일은 설정의 저장한 PDF·동영상에서 삭제하거나 파일 앱에서 관리할 수 있습니다. 앱을 삭제하면 앱 내부 데이터가 삭제됩니다. 사진 앱 또는 외부에 내보낸 사본과 시스템 백업은 별도로 삭제해야 합니다.

iOS 기기 백업 및 사용자가 파일 앱에서 선택한 iCloud·외부 저장 서비스에는 해당 시스템·서비스의 정책과 설정이 적용됩니다.

공유 버튼을 누르면 iOS 공유 시트가 열립니다. 사용자가 선택한 파일과 받는 앱·서비스에만 공유하며, 공유 이후에는 받는 서비스의 개인정보처리방침이 적용됩니다.

광고 식별자, 위치, 광고 추적 또는 사용자 프로파일링을 사용하지 않습니다. 페이지 중복 확인용 이미지 밝기 정보는 기기에서 문서 비교에만 사용합니다.

촬영 방식 확인 화면의 진단 정보는 메모리에만 유지됩니다. 진단 공유를 누르면 앱 버전, iOS 버전, 촬영 경로·해상도·횟수만 공유 시트에 전달합니다. 사진 내용이나 기기 고유 식별자는 포함하지 않습니다.
