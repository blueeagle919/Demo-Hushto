Hushto 고객지원

게시 전 초안: 개발자명과 문의 연락처 확정 후 공개 서버에 게시해야 합니다.

iOS 설정 → Hushto → 카메라 권한을 확인해주세요. 다른 카메라 앱을 닫고 다시 시도해주세요.

시뮬레이터는 실제 카메라가 없어서 샘플 프레임을 사용합니다. 실제 촬영과 촬영음은 iPhone에서 확인해야 합니다.

밝은 곳에서 문서를 화면 안에 충분히 크게 맞추고 기기를 고정해주세요. 무음 모드는 공식 무음 사진 촬영 지원 여부에 따라 최대 사진 크기 또는 최대 네이티브 영상 프레임을 저장합니다. 실제 해상도는 설정의 촬영 방식 확인에서 확인해주세요. 작은 글씨는 문서에 가까이 다가가 촬영해주세요.

페이지 관리에서 순서를 변경하고 PDF 만들기를 선택하세요. 동일한 이름의 PDF가 있으면 다른 이름을 입력해주세요. 저장 오류가 발생하면 기기 저장 공간을 확인해주세요.

파일 앱 → 나의 iPhone → Hushto에서도 파일을 관리할 수 있습니다. 앱 안에서 파일을 삭제해도 이미 공유한 사본은 유지됩니다.

문제를 보고할 때 앱 버전, iPhone 모델, iOS 버전과 재현 단계를 함께 알려주세요. 문서 사진에는 개인정보가 있을 수 있으므로 필요하지 않은 사진은 보내지 마세요.
