# Hushto 보완 및 저메모리 최적화 — 2026-10-25

이전 사용자 검증에서 발견한 저장 복구 결함과 접근성 문제를 보완했다. 기존 화면 배치와 모드별 저장 동작은 유지했다.

## 수정
- 사진·동영상은 Photos 저장 전에 앱 내부 파일로 임시 보관한다. 저장 실패 후 강제 종료해도 다음 실행에서 재시도할 수 있다. 일반 저장 성공 시 임시 파일을 정리한다.
- 복구 시 전체 이미지를 디코딩하지 않고 파일 URL로 Photos에 전달한다. 동영상은 파일 이동으로 보관해 메모리 복사를 피한다.
- 백그라운드 저장 작업 시간을 요청하고, 재실행에서 복구한 촬영본은 사용자가 사진 앱 저장 여부를 확인하고 재시도하도록 한다.
- 카메라 모드·보정 도구 접근성 이름을 개별 항목으로 제공한다. 자르기 모서리에 가로·세로 좌표 설명을 추가했다.
- RAM 3GB 이하에서는 화면용 미리보기 최대 변 900px, 자르기용 1536px, 미리보기 캐시 6MB, 썸네일 캐시 4MB로 제한한다. 일반 기기는 각각 1200px·2048px·16MB·12MB다. 원본 저장 해상도와 PDF 품질 설정은 유지한다.
- 메모리 경고 시 재생성 가능한 이미지·보정 캐시를 비운다. 자르기 종료 후 큰 미리보기 참조를 해제한다.
- 저메모리 기기는 자동 검출 간격을 0.4초로, 심한 발열 상태는 0.75초로 조절한다. UI에 전달할 값이 바뀔 때만 갱신하고 대기 중인 UI 콜백이 원본 카메라 프레임을 붙잡지 않도록 했다.
- 기존 비동기 세션 복원, 이미지 축소 디코딩, PDF 축소 디코딩, 보정 미리보기 원본 재사용 최적화도 유지한다.

- 임시 파일을 쓰기 전 저장 공간이 완전히 부족하면 영구 보관을 보장할 수 없다. 이 경우 앱을 종료하지 말고 공간 확보 후 재시도하라는 오류를 제공한다.
